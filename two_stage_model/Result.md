# 260705 two_stage_model 実験ログ

## 概要

`popularity=0` の曲を明示的に扱うため、0/非0分類モデルと、非0曲のみを対象にした回帰モデルを組み合わせた 2 段階モデルを試した。

## 実験条件

* 実行ファイル: `two_stage_model/two_stage_model.py`
* Fold 数: 5
* 分類モデル: `CatBoostClassifier`
* 回帰モデル: `CatBoostRegressor`
* 回帰モデルの学習対象: `popularity > 0`
* 予測方式: 閾値方式
* 使用閾値: `threshold=0.5`

## データ

* train: `(79800, 76)`
* test: `(34200, 76)`
* `popularity == 0` の割合: `0.1401`
* `popularity == 0`: 11,179 件
* `popularity > 0`: 68,621 件

## CV 結果

| 指標            |       値 |
| ------------- | ------: |
| 2段階モデル CV MSE | 63.9016 |
| 分類 accuracy   |  0.9845 |
| 分類 precision  |  0.9923 |
| 分類 recall     |  0.9896 |
| 0 の曲に対する平均予測値 |  0.9424 |
| 非0の曲に対する MSE  | 68.2682 |

閾値方式では、`threshold=0.6` が最も良かった。

## 確率掛け合わせ方式

| 方式      |  CV MSE |
| ------- | ------: |
| 確率掛け合わせ | 63.0879 |

今回試した中では、確率掛け合わせ方式が最も良い CV MSE となった。

## 特徴量重要度メモ

回帰モデルでは、以下の特徴量の重要度が高かった。

1. `album_name`
2. `track_genre`
3. `main_artist`
4. `album_count`
5. `te_track_genre`

音響特徴量だけでなく、アルバム名、ジャンル、アーティスト情報が強く効いている。

## 考察

0/非0分類の性能は高く、`recall=0.9896` と安定していた。
`popularity=0` の曲に対する平均予測値も 0.9424 であり、0 の曲を明示的に扱う効果は出ている。

一方で、非0の曲に対する MSE は 68.2682 と高めであり、非0曲の具体的な人気度を当てる部分には改善余地がある。

また、`threshold=0.5` よりも `threshold=0.6` の方が CV MSE は良かった。さらに、確率掛け合わせ方式では CV MSE が 63.0879 まで改善した。
